# MANGANI v0.5.0 — Templates

MANGANI creates, serves, extends and builds small offline-capable web projects using plain HTML, CSS and JavaScript.

## Added

- Built-in template registry with `basic` (default) and `dashboard` starters.
- `mangani create <name> --template <template>` selection.
- Template identity in new `mangani.config.json` files.
- Public template registry API.
- Packed-package installation checks in CI and automatic GitHub releases after verification.

## Compatibility

- Requires Node.js 20 or newer.
- Existing configurations without `template` remain supported.
- Both templates use the existing development server, live reload, generators and static build system.
- Generated projects require no runtime dependencies or remote template downloads.

## Verification

- Syntax checks and 41 source tests on Node.js 20 and 24.
- Actual npm tarball installed offline, with CLI version/help and public API checks.
- Both packed templates checked through creation, generation, HTTP serving and production builds.

## Installation

Download `bmk24-mangani-0.5.0.tgz` from this release, then run:

```sh
npm install --global ./bmk24-mangani-0.5.0.tgz
mangani --version
mangani create my-site --template basic
```

The GitHub release does not publish to the npm registry. On 2026-09-30, the public registry returned 404 for `@bmk24/mangani`; use the release tarball or the repository installation instructions.

## Scope

Remote/third-party templates, framework starters, TypeScript transforms and deployment automation remain outside v0.5.
